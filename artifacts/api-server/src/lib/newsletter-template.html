Worth knowing

Long context is quietly changing how people file things

The interesting shift isn't summarising, it's that you can stop organising documents before you use them. I dropped a year of unsorted notes into one prompt and got back an index I actually kept. Retrieval plumbing starts to look optional for small personal corpora. Read the write-up

Small models are now good enough to run on the desk

A 4B model handles classification and extraction well enough that I've moved two internal jobs off an API entirely. Latency was the real win; cost was never my bottleneck. Benchmark it on your own data before believing anyone's chart. Benchmarks and caveats

Evals are turning into the actual product work

Every team I spoke to this month said the same thing in different words: the prompt took a day, the test set took a month. The teams shipping confidently are the ones who wrote down what "good" means before they started. Unglamorous and completely decisive. A practical starting template

Voice interfaces got usable while nobody was watching

Round-trip latency under half a second changes the feel completely — it stops being dictation and starts being conversation. I've been using it for first drafts on the drive home. Still bad at anything requiring precise numbers. Short demo and notes
 

What I've been building

Most of my week went into the small app that sends this newsletter. It's deliberately unimpressive: a folder of markdown, a template, and a send button. I wanted the writing to be the only hard part, and it took two rebuilds to get there because I kept adding features nobody asked for, including me.

The other thread was a triage assistant for my inbox — not automated replies, just ranking and a one-line reason for each. It's been running a fortnight and the useful discovery is that I disagree with it about once a day, which is roughly the rate I'd disagree with a competent assistant. That feels like the right bar.
 

One thing to try

Take the last thing you wrote for work and ask a model to argue against it in three bullet points, then rewrite only the weakest one. Ten minutes, and it's a better use of the tool than asking it to write for you. I've started doing it before I send anything that matters. The prompt I use
